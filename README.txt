BIRTHDAY CALENDAR - PROJECT FILES

CONNECTED APP (recommended): read FIREBASE-SETUP.txt first, then build the APK.

BUILD THE APK WITH GITHUB (free)
1. Create a GitHub repository and upload ALL files from this folder.
2. Hidden folders like .github are often skipped when uploading. If you do not see
   .github/workflows/build-apk.yml in your repository:
   - Click Add file > Create new file
   - Type this name exactly: .github/workflows/build-apk.yml
   - Paste the text from build-apk.yml.txt and commit.
3. Open the Actions tab > Build APK > Run workflow. Wait about 5 minutes.
4. Download "birthday-calendar-apk" (a ZIP), UNZIP it, install app-debug.apk.
   Uninstall any older version first.

ONLINE APK MAKER (WebIntoApp, AppsGeyser, Median...)
Do NOT upload this project. Use birthday-calendar-web.zip (index.html at the top).
